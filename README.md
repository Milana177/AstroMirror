# AstroMirror - Астрологическое зеркало

## Краткое описание
AstroMirror — это веб-приложение для астрологических практик и самопознания. Пользователи могут получать персонализированные прогнозы, строить натальные карты, рассчитывать матрицу судьбы и получать толкования карт Таро. Приложение сохраняет историю запросов в облачной базе данных и персонализирует контент для авторизованных пользователей.

## Ключевой функционал
1. Регистрация и авторизация (JWT).
2. Расчеты: Карта дня, натальная карта, матрица судьбы, гадания.
3. Личный кабинет: История всех расчетов и гаданий с возможностью фильтрации.
4. Избранное: Сохранение важных результатов раскладов.

## Технологический стек

### Frontend
- **HTML5/CSS3/JavaScript (ES6+)**
- **Fetch API** — для взаимодействия с API сервера
- **LocalStorage** — для хранения JWT-токена сессии

### Backend
- **Node.js + Express.js** — REST API для обработки запросов
- **jsonwebtoken (JWT)** — для авторизации
- **bcrypt** — для хеширования паролей

### База данных
- **MySQL** — для хранения пользователей, истории раскладов и состояний "Избранное"

### Инфраструктура
- **Хостинг бэкенда:** Render / Railway
- **Хостинг фронтенда:** Vercel / GitHub Pages

## Схема данных (MySQL)

### Таблица users
| Поле | Тип | Описание |
|------|-----|----------|
| id | INT | PRIMARY KEY, AUTO_INCREMENT |
| name | VARCHAR | Имя пользователя |
| email | VARCHAR | Email (UNIQUE) |
| password | VARCHAR | Хэшированный пароль |

### Таблица history
| Поле | Тип | Описание |
|------|-----|----------|
| id | INT | PRIMARY KEY, AUTO_INCREMENT |
| user_id | INT | FOREIGN KEY (users.id) |
| type | VARCHAR | Категория (tarot, natal, matrix) |
| data | JSON | Результат расчета |
| is_favorite | BOOLEAN | Статус избранного |
| created_at | TIMESTAMP | Дата сохранения |
