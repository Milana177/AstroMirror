# AstroMirror — Астрологическое зеркало

## Краткое описание
AstroMirror — это веб-приложение для астрологических практик и самопознания. Пользователи могут выполнять астрологические расчеты, сохранять историю запросов и управлять своими данными в личном кабинете.

## Ключевой функционал
1. **Авторизация:** Безопасная регистрация и вход (JWT).
2. **Личный кабинет:** История всех запросов (Таро, Натальные карты, Матрица судьбы).
3. **Фильтрация и сортировка:** Управление списком раскладов по категориям, дате и статусу «Избранное».
4. **Безопасность:** Защита приватных страниц от неавторизованного доступа.

## Структура приложения

| № | Раздел | URL | Тип доступа | Описание |
|---|--------|-----|-------------|----------|
| 1 | Главная | `/index.html` | Публичный | Лендинг с навигацией |
| 2 | Вход / Рег. | `/login.html` | Публичный | Авторизация пользователя |
| 3 | Личный кабинет | `/profile.html` | Приватный | История, фильтры, избранное |

## Технологический стек

### Frontend
- **HTML5/CSS3/JavaScript** — клиентская часть и управление интерфейсом.
- **Fetch API** — для взаимодействия с API сервера.
- **LocalStorage** — для хранения токена сессии.

### Backend
- **Node.js + Express.js** — REST API для обработки запросов.
- **jsonwebtoken (JWT)** — для авторизации.
- **bcrypt** — для защиты паролей.

### База данных
- **MySQL** — хранение пользователей и истории раскладов.

## Схема данных (MySQL)

### Таблица users
| Поле | Тип | Описание |
|------|-----|----------|
| id | INT | PRIMARY KEY |
| name | VARCHAR | Имя |
| email | VARCHAR | Уникальный Email |
| password | VARCHAR | Хэш пароля |

### Таблица history
| Поле | Тип | Описание |
|------|-----|----------|
| id | INT | PRIMARY KEY |
| user_id | INT | ID владельца (Foreign Key) |
| type | VARCHAR | Категория (tarot, natal, matrix) |
| title | VARCHAR | Название расклада |
| description | TEXT | Текст/результат расчета |
| is_favorite | BOOLEAN | Статус избранного |
| created_at | DATETIME | Дата создания |

## Инструкция по локальному запуску
1. Клонировать репозиторий.
2. Установить зависимости: `npm install`
3. Создать базу `astromirror` в MySQL и запустить `server.js`.
4. Создать `.env` файл с настройками подключения к БД (DB_HOST, DB_USER, DB_PASS, DB_NAME).
